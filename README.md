# Batalha do Folclore

Jogo de cartas 2D original inspirado nas lendas brasileiras. Feito com HTML, CSS e JavaScript puro, sem dependências nem etapa de compilação.

## Como jogar
Abra `index.html` em um navegador ou publique a pasta no GitHub Pages.

## Regras
- Partida local contra o computador com seis rodadas.
- Três territórios; o poder de cada carta soma ataque e defesa.
- A energia aumenta a cada rodada e limita as cartas jogadas.
- Algumas cartas recebem bônus em territórios específicos.
- Vence quem conquistar mais territórios ao fim da sexta rodada.

## Publicação
O workflow `.github/workflows/deploy-pages.yml` publica a branch `main` no GitHub Pages. Em Settings → Pages, selecione **GitHub Actions** como fonte. Multiplayer online e salvamento de progresso não fazem parte deste protótipo.
